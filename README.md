# pyspark_retail-data-pipeline
A project to demonstrate how to extract/(create) raw data,clean using principles of  Medallion Architecture and extract some business insights using distributed processing software Apache Pyspark

# PySpark Retail Data Pipeline
This project is an end-to-end Data Engineering pipeline built using Apache Spark (PySpark). The objective was to understand how raw data moves through different stages of processing, from ingestion to business-ready analytics, while gaining hands-on experience with distributed data processing, Docker, and the Medallion Architecture.

The pipeline starts by generating a synthetic retail dataset, processes it through the Bronze, Silver, and Gold layers, validates the output at each stage, and finally produces datasets that can be visualized using Power BI.

# Project Overview
The project follows the Medallion Architecture:
- **Bronze Layer** stores the raw ingested data.
- **Silver Layer** cleans and validates the Bronze data.
- **Gold Layer** creates analytical datasets for reporting and business insights.

The Spark cluster runs inside Docker and consists of one Spark Master and two Spark Worker nodes.

# Pipeline Workflow

## 1. Generate Raw Data
The project begins by creating a synthetic retail dataset using:
```bash
python generated_raw_data.py
```
The generated CSV acts as the input for the Spark pipeline.
The raw dataset is intentionally excluded from GitHub because it can always be recreated using the script above.

## 2. Bronze Layer
The Bronze layer performs the initial ingestion of the dataset with minimal transformations.
The script:

- Reads the raw CSV dataset
- Defines the schema
- Converts the data into Parquet format
- Adds ingestion metadata
- Partitions the output by `ingestion_date`
The objective of this layer is to preserve the original data while storing it in an efficient format for downstream processing.

## 3. Silver Layer
The Silver layer focuses on improving data quality before any business analysis is performed.
The script performs operations such as:
- Removing duplicate records
- Filtering invalid or incomplete records
- Basic data validation
- Cleaning the dataset
- Partitioning the output by `order_status`
This layer contains clean and reliable data that can safely be used for analytics.

## 4. Gold Layer
The Gold layer generates business-ready datasets from the cleaned Silver data.
The project creates multiple analytical datasets including:
- Daily Sales Metrics
- Monthly Sales Metrics
- City Revenue Metrics
- Product Category Performance
- Top Products
- Audit Metadata
These datasets are used for reporting and Power BI visualizations.

# Validation
Separate validation scripts are included for each layer of the pipeline.
These scripts verify that:
- the expected schema is created,
- transformations have been applied correctly,
- record counts remain consistent, and
- output datasets are generated successfully.

This project runs entirely inside Docker using the official Apache Spark image.
Since all required dependencies are already available inside the Docker containers, there is no need for a separate Python virtual environment or a `requirements.txt` file.

# Running the Project

Clone the repository:
```bash
git clone https://github.com/baibhabg5/pyspark_retail-data-pipeline.git
```
Move into the project directory:
```bash
cd pyspark_retail-data-pipeline
```
Start the Spark cluster:
```bash
docker compose up -d
```
Generate the raw dataset:
```bash
python generated_raw_data.py
```
Run the pipeline:

```bash
python app/retail_bronze.py
python app/retail_silver.py
python app/retail_gold.py
```
(Optional) Run the validation scripts:
```bash
python app/bronze_validation.py
python app/silver_verification.py
python app/gold_validation.py
```
